Agent 連接尚未連接

      
只要完成以下三步，就能連接你的 Agent。

      
1. 點擊下方「複製 Webhook 建立提示詞」。
2. 把提示詞貼到任何 Agent 的聊天視窗並送出。
3. Agent 會回傳一個連接地址；把它貼到下方欄位，再點擊「連接並測試」。

      
如果 Agent 回覆 UNSUPPORTED_WEBHOOK，代表它目前無法建立連接地址；請改用其他有部署能力的 Agent。
